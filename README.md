## Publicar
No GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
A publicação pode levar alguns minutos. Depois, futuras alterações na branch main podem atualizar o site automaticamente.

## Editar imagens
As imagens estão em `assets/`. Para acrescentar fotos no GitHub, entre na pasta `assets`, escolha **Add file → Upload files**, selecione as imagens e confirme em **Commit changes**. Em seguida, atualize o caminho no `index.html`, por exemplo `<img src="assets/nova-foto.webp" alt="Descrição da imagem">`.
